## Technical SEO: see SEO_AUDIT.md

The check found 0 broken internal links across 77,022, 0 hreflang errors and 0 JSON-LD parse errors. 309 warnings are accepted: 301 of them are long titles caused by long startup names, and 8 are descriptions.

## Performance, architecture and tests: see PERFORMANCE_REPORT.md

- **Performance:** mobile Lighthouse scores went from 82–93 to 97–100. The fixes were a self-hosted font, rendering only the first 24 home cards and an HTML file 22–31% smaller.
- **Architecture:**
  - The site address is now one setting (`package.json` "homepage").
  - The search code is shared by the build and the browser.
  - `textOf` moved into `harvest.mjs`, so importing it no longer runs the enrichment pipeline.
- **Tests:** CI previously checked only the data schema. It now runs:
  - `check-data`
  - unit tests (`npm test`)
  - `audit-data --strict`
  - `audit-seo --strict`
  - 10 Playwright end-to-end tests (`npm run e2e`)

  Any failure stops the deploy.
- **Dependencies:** `npm audit` reports 0 vulnerabilities. One runtime dependency was added: `@fontsource-variable/readex-pro`, which replaces the Google Fonts request.

## Monitoring

- **Data health:** the `audit-data` and `audit-seo` reports are rebuilt on every CI run.
- **Search engines:** IndexNow is pinged after each deploy. The first ping returned HTTP 200.
- **Analytics:** a privacy-friendly GoatCounter hook is ready, including a zero-result-search event. It stays off until `goatcounter` is set in `src/config.ts`.
- **AI answers:** `automation/llm-visibility.md` lists 20 monthly test questions in English and Arabic.
