Image usage

Terms for using the directory's logo, share-card artwork and credited photos, with details on requesting permission.

Original artwork

The directory's logo and original share-card artwork are © Shark Tank Egypt Directory. Reusing this artwork requires permission.

Images from other sources

Portraits, business photos, screenshots and show stills belong to their respective owners, including when they appear inside a share card. Follow the credit link on the relevant profile to find the source, and contact the rights holder for reuse terms. A source credit does not grant permission to reuse an image. The directory cannot license these images.

Request permission

To request permission for our original artwork, open a GitHub issue with the image URL and a description of how you plan to use it. Wait for written approval before reusing the artwork.
